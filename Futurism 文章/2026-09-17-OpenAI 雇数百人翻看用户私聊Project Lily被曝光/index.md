# OpenAI 雇数百人翻看用户私聊，「Project Lily」被曝光

> 404 Media 爆料，OpenAI 正雇数百名员工逐条阅读用户发给 ChatGPT 的提问，其中包含敏感个人信息，甚至包括用户明确要求保密的对话——多数用户对此毫不知情。

![封面图](./cover.jpg)你向 ChatGPT 倾诉的秘密，可能正被屏幕另一端的人工审阅者逐字读过。

## 不是审核，是「调教」

如果你有一天忍不住对 ChatGPT 倒苦水，那么请记住：你的话可能是有听众的。

据 404 Media 报道，OpenAI 正在招募数百名员工，逐条翻看并阅读用户的提示词（prompt），其中不少含有敏感的个人信息。这项工作并不是内容审核。相反，OpenAI 希望通过审阅这些提示词来改进 ChatGPT 给出的回复——合同工会对 AI 的每一条回复打分和批评。404 看到的内部文件显示，项目重点在于把 ChatGPT 往「少把自己当人、少一味奉承用户」的方向推。

而「拟人化」与「谄媚」这两种特质，恰恰因在所谓「AI 精神病」（AI psychosis）中的角色而饱受审视——在这类案例里，AI 会煽动并助推用户的妄想行为。已有多起诉讼指控，由 GPT-4o 驱动、限制更少的旧版 ChatGPT 把用户推向了自杀。

## 用户根本不知道有人在读

代价也很明显。这项被命名为「Project Lily」的聊天监控行动，如果用户知道它存在，多半会视之为对隐私的惊人侵犯。

当被问及 ChatGPT 用户是否知道有人在读他们的聊天时，一名员工回答：「不知道。」

「我不觉得他们会想象到，某个地方的某个外包员工……正在分析这些对话。」这名员工对 404 说。

目前仍不清楚有多少提示词会被读取，也不知道 OpenAI 如何挑选它们。但 404 发现，其中一些对话里，用户明确要求 ChatGPT 为他们的聊天保密。被选中的提示词虽然经过匿名化处理，有时仍包含个人信息；员工使用的后台还带有一份「用户记忆摘要」，能提供过往对话的细节，甚至能推断出用户住在哪里。

当 404 联系 OpenAI 时，公司称它用一个名为「Privacy Filter」的模型来匿名化对话，而其官网也承认该模型「可能出错」。

## 遮遮掩掩的说明义务

OpenAI 在这个问题上的姿态，堪称躲闪。它以审核和安全为由让员工阅读用户消息，这早已是公开的秘密，但对于「是否明确告知过用户，有人类在阅读提示词以改进 AI」这一问题，它没有回应 404。

直到 404 发表报道之后，它才指向官网的一个页面，上面写着人类可能审查提示词以「改进模型表现」。用户可以通过关闭「improve the model for everyone」（为所有人改进模型）设置来退出这一做法，但该设置默认开启。

## 聊天框自带的「虚假亲密感」

民主与技术中心（Center for Democracy and Technology）高级研究员 Michal Luria 对 404 表示，人工审查「对安全而言可能是必不可少的」，但她同时指出，「聊天机器人界面会自动制造出一种虚假的亲密感和隐私感」。

「这与社交媒体上的内容审核有本质区别，因为在社交媒体上发布内容，本就意味着预期到平台会审核、内容会被公开。」Luria 补充道。

无论如何，OpenAI 似乎确实很在意自家 AI 说话的样子。例如员工会标记并记录下「AI 腔」和「不必要地使用 emoji」的情况——这些是聊天机器人的常见破绽。一份发给员工的文件解释道：「在筹划植树节庆祝活动时用一个树 emoji 是恰当的，但在讨论死亡时用骷髅 emoji、在报道致命空难时用飞机 emoji，就不合适了。」

水面之下或许还有更多。提供给审阅者的一份常见问题说明称，他们不必操心核实回复的真实性，并暗示还有其他项目团队「负责内容核实」。

## 一条默认开启的开关

整套安排里最耐人寻味的，是那个默认开启的选项：只要用户不主动关闭，就等于默认把自己的对话交给人类翻阅。而对那些以为「聊天框另一头只有 AI」的人来说，这个默认值本身就是一种错觉。
