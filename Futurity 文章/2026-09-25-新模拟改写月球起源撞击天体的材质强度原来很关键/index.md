# 新模拟改写月球起源：撞击天体的"材质强度"原来很关键

> 一项新模拟首次把两个原始天体的"材质强度"纳入计算，发现撞击前地球与 Theia 的温度差异，可能决定月球是在撞击后几小时内一体成形，还是由碎片盘慢慢聚拢。

![封面图](./cover.jpg)新的大碰撞模拟显示，撞击天体的地质强度与温度，可能决定月球的成形方式。

## 一直被当成"流体"处理的天体

以地球的体积和所处的轨道位置来说，它有一颗大得反常的卫星。而地球究竟如何获得这位伴侣，长期困扰着研究者。

美国西南研究院（SwRI）与亚利桑那大学的研究者，用最先进的计算方法，揭示了约45亿年前一颗火星大小的天体撞击地球、月球由此诞生这一过程中的根本差异。成果发表在《天体物理学杂志快报》上，首次把两个原始天体的材质强度纳入考量，可能改变研究者对这场行星碰撞的理解，也有助于约束撞击发生的时间。

"我们发现，那颗火星大小原始月球自身的既有地质构造是有影响的，"论文作者 Adeene Denton 说。她曾是月球与行星实验室的博士后，现就职于 SwRI。"当你把地球和月球当作具有地质属性的碰撞天体来模拟，月球的形成方式就会不一样——这一点我们此前认为无关紧要。"

## 从"无差异流体"到有强度的岩石

早期的大碰撞研究包括2001年 Robin Canup 与 Erik Asphaug 的一篇奠基性论文。Canup 是 SwRI 太阳系科学与探索部门（位于科罗拉多州博尔德）的副总裁，Asphaug 则是月球与行星实验室教授、本次研究的合著者。在那套图景里，名为 Theia 的火星大小天体撞上早期地球后彻底解体，残骸在地球周围散成一个盘。但那些模拟以及后续的大碰撞建模都忽略了材质强度，认为在如此高能的撞击中它无足轻重。

Denton 团队重新审视了这一假设，首次用上随温度变化的地质强度。"因为这场碰撞被认为剧烈到足以熔化和汽化地球与 Theia 的大部分，此前的论文便假定把它们近似成流体是可以接受的，"Asphaug 说，"但根据我们的新结果，我们认为是时候重新考虑这一点了。"

团队采用更先进的光滑粒子流体动力学（SPH）模拟，把碰撞天体的结构强度算了进去。这套 SPH 版本由亚利桑那大学与瑞士伯尔尼大学开发，其强度模型赋予天体接近真实地质材料的抗变形能力——构成 Theia 与原始地球的岩石和金属，或是固态冰。天体越热越"软"，团队发现，月球形成的不同结局对碰撞天体的温度十分敏感：有些场景下，撞击后数小时内就诞生一颗完整成形的月球；另一些场景下，则先在地球周围形成原始月球盘，再由它慢慢聚合成月球。

## 五小时就能"长出"一个月亮？

由于原行星通常诞生时很热、随后随年龄冷却，这就把大碰撞发生的时间与月球初始状态、组装方式联系了起来。

"取决于碰撞前地球和月球有多热，撞击可能摧毁 Theia，甩出巨大的碎片盘，最终形成月球，"Denton 说，"但当我们采用与原始撞击建模相同的参数——连同两个天体内部相同的温度结构——大约五个小时内，一颗完整的月球就出现了。"

完整月球成形的结局在此前模拟中也出现过，但这项工作首次表明，材质强度与温度在"月球是一体成形还是由原始月球盘中的物质聚合而成"上起着核心作用。

未参与该研究的 Canup 评价说："这些令人惊讶且振奋的新结果，暗示了当今月球的一些物理性质——或许包括它的挥发性物质含量——与大碰撞发生时地球和 Theia 热状态之间可能存在联系。这反过来可能帮助科学家更好地约束月球形成事件发生的时间。"

## 剩下的老难题：地球和月球为何如此相似

另一个未解之谜仍是地球与月球物质构成的相似性。与以往模型一样，解释二者高度接近的成分组合，依旧是悬而未决的科学问题。

"因为地球和火星在太阳系的同一片区域形成，它们像是一对兄弟，"Denton 说，"而月球和地球，更像是异卵双胞胎。"一种可能的解释是：Theia 与原始地球来自太阳系的同一区域，而成分上与地球、月球截然不同的火星，则形成于更远处。

"我们现在知道，地球与 Theia 的地球物理状态对碰撞结局起着根本作用，"合著者、Asphaug 课题组博士生 Namya Baijal 说，"这给了我们一条新途径，去探索撞击发生时的条件，以及它们可能揭示的月球起源之谜。"
